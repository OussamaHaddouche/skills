# skills

Agent skills for Cursor and the [open skills ecosystem](https://skills.sh/).

## Install

All skills:

```bash
npx skills add OussamaHaddouche/skills
```

One skill:

```bash
npx skills add OussamaHaddouche/skills@skill-name
```

## Skills

Add each skill as a folder with a `SKILL.md`:

```text
skills/
  my-skill/
    SKILL.md
  another-skill/
    SKILL.md
    scripts/        # optional
```
